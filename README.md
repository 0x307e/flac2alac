# flac2alac

入力ディレクトリを走査し、FLAC を ALAC (.m4a) に変換する。FLAC 以外のファイルは変換せず、同じ相対パスのまま出力ディレクトリへそのままコピーする。

## 使い方

```
go build
./flac2alac <入力ディレクトリ> <出力ディレクトリ>
```

- 拡張子の大文字小文字は区別しない。`.flac` も `.FLAC` も `.Flac` も変換する。
- 出力パスは入力ファイルの相対パスから組み立てる。親ディレクトリ名が `FLAC` でも出力先の名前は変わらない。
- コピーはバイト単位で一致し、パーミッションと更新時刻を引き継ぐ。
- 変換に失敗したファイルはエラーを標準エラーに 1 行ずつ出し、`N of M files failed` を表示して終了コード 1 を返す。失敗した `.m4a` は残さない。
- 出力ディレクトリが入力ディレクトリの中にある指定は拒否する。
- 出力ディレクトリに既にあるファイルは上書きする。途中で失敗しても同じコマンドを再実行すれば同じ状態に収束する。

必要なもの: Go 1.26 以上、`ffmpeg`。

## 検証

```
./scripts/e2e.sh
```

実際の FLAC と FLAC 以外のファイルを作り、変換結果のコーデック、コピーの一致、パーミッション、終了コードまで確認する。`ffmpeg` と `ffprobe` が PATH にあること。
